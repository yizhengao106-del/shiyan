## 第四章的协同路线（拟组合，不是已完成结果）
原始每层MHSIU先产生融合特征。A在第3、2级改变尺度选择权重；B在第2、1级细节增强；随后C在第4至1级将当前特征与上一级解码输出做门控融合；最后仍经原hmu。
B的边缘头接末级解码特征，属于辅助训练分支，不是串行送往下一解码层的模块。
因此组合后的准确顺序是：三尺度特征 -> MHSIU（部分级用A）-> 部分级用B -> 相邻层融合（C）-> 原RGPU -> 分割头，同时末级接边缘监督。
这个安排在接口上可行，但尚未实现/验证A+B+C；相互兼容不等于相互增益。章节应暂称三个组成模块，不宣称三个独立原创。

## 第五章必须明确基准
现有E和F都是“原版+单模块”，不能直接描述为“在第四章最终模型上进一步优化”。
方案一：第五章作为另一条基于原版ZoomNeXt的研究路线，原版+E/F/G及其组合，与第四章方法比较。这与当前代码最接近。
方案二：第五章明确继承第四章最终模型M4，那么要补M4、M4+E、M4+F、M4+E+F等对照；原版+E不能替代M4+E的消融证据。
两条路线均可，不能在文字上继承、实验上却用不同基准。若G是依赖F的门控扩展，G单独组定义为“原版RGPU上增加深度条件注入”或省略独立G、以F对F+G隔离增量，需事先规定。

## G的可实现方案（未编码、未训练）
D=StopGradient(DepthEstimator(I))；DepthEstimator冻结；经按图归一化、投影和对齐得到Ds。
在F原共享特征C和组特征Xi基础上：

    delta_i = DepthGate_i(Concat(Xi,C,Ds))
    gi = Sigmoid(original_group_logit_i(Xi,C) + delta_i)
    Xi_new = Xi + tanh(ai)*gi*C

可使深度delta输出零初始化，使增加G时初始退化为F。输入维度、是否加入深度梯度、可靠性门控、接入阶段仍是待确定设计，不可写成已实现。
这是“深度条件门控”，不是严格“深度约束损失”。若要称约束，必须另行定义监督/正则及系数。
深度从RGB估计，属于外部预训练模型提供的派生先验，不是深度相机新增的独立观测。推理也需要该先验，必须计入生成成本；增强时RGB、mask和depth要几何同步。

## 3. A：浅层特征引导的分组尺度权重修正

### 代码及接入
`WeightGuided-guidance-20260910①/methods/zoomnext/weight_guided.py`：ShallowGuidedMHSIU、EffB1_ZoomNeXt_WeightGuided。
配置wg_guidance.py：use_weight_guidance=True，frequency/edge=False，guided_stages=(3,2)。不等于此前FDER+SG的浅层特征直接添加版本。

### 动机（待验证假设）
不同尺度提供不同的局部细节和上下文信息。浅层特征可能帮助尺度选择保留细节；但也可能引入背景纹理，不能写成已证明的普遍优势。

### 真实计算
以中间输入尺度的编码器第一级mf[0]（B1为16通道）作为G，不使用真值掩码。原MHSIU保留三尺度预处理、value分支和分组结构。原中尺度特征m（已经MHSIU分支卷积）与G分别经过1×1投影到16通道；G投影后用自适应平均池化对齐至目标尺寸，必要时插值。

    Gt = Align(Conv1x1(G))
    Mt = Conv1x1(m)
    delta = Conv1x1(ReLU(Conv3x3(Concat(Mt,Gt))))
    W = Softmax_scale(original_logits + delta)
    output = GroupMerge(sum_scale(W * original_values))

delta输出3×组数通道（默认4组，即12），重排为[B*4,3,H,W]，每组每位置对三尺度归一化。末层delta卷积权重、偏置为零，初始权重计算退化为原版。guide参加反向传播，不detach。只改siu_3、siu_2，其他阶段不改。

### 可用方法段落
在原有分组尺度融合结构中，引入中尺度输入的浅层编码特征作为辅助条件。通过轻量卷积计算分组尺度logit的残差修正，在保留原值分支的情况下调节三尺度贡献。该设计将浅层引导用于融合权重生成，而非直接向解码特征相加，并通过零初始化保持初始融合行为与原结构一致。

### 证据与消融
NC4K小幅改善Sm/wFm、MAE持平；历史CAMO为0.831/0.773/0.061，低于原train的0.834/0.778/0.060。因此不是已证实全面提升。
需要对比无guide、只用目标特征、不同接入层、非零初始化；分析尺度权重图及按目标大小分类的表现。重点核查与已有浅层引导/条件注意力工作的区别。

## 4. B2：池化细节增强与边缘辅助监督

### 代码及接入
`ZoomNeXt-②频率增强与边缘监督-20260911/methods/zoomnext/layers.py`：FrequencyDetailEnhancer、EdgeReconstructionHead；调度在weight_guided.py，边缘目标函数在zoomnext.py。
配置wg_fder.py：guidance=False，frequency=True，edge=True，edge_loss_weight=0.3。它是两个操作组成的一组实验，不是只加一个边缘损失。

### 真实计算
对第2、1级MHSIU输出X，先增强，再与上一级解码特征相加，再经过原hmu。

    L = AvgPool3x3(X, stride=1, padding=1)
    H = X - L
    Lp = CBR1x1(L)
    Hp = CBR3x3(H)
    Hg = Hp * sigmoid(Conv1x1(Hp))
    Xout = X + CBR3x3(Concat(Lp,Hg))

这里的低频是局部平滑近似，高频是减去平滑后的残差；没有FFT/DCT/小波、频谱变换或明确频带划分。不能写成严格频域分解或完整FEDER算法复现。

最后一级解码特征经双线性上采样2倍、3×3卷积64->32、ReLU、1×1卷积32->1形成边缘logits。目标为GT掩码的3×3膨胀减腐蚀，clamp到[0,1]。训练目标：

    loss = BCE(seg_logits, mask) + lambda(t)*mean(1-(2*sigmoid(seg_logits)-1)^2)
           + 0.3*BCE(edge_logits, edge_target)

lambda(t)沿用原版余弦进度系数。真值边缘只用于训练；推理输出分割logits，不输入真值边缘。现存forward仍会计算边缘头，因此不能声称当前实现推理零开销。

### 可用方法段落
对高分辨率解码阶段的融合特征进行局部平滑与残差细节分解，分别编码平滑分量和细节分量，并对细节响应进行门控后残差融合。同时在末级解码特征上增加边缘预测辅助任务，通过掩码生成的边缘目标约束训练，以探索细节增强与轮廓监督对伪装目标分割的作用。

### 证据与消融
历史CAMO0.838/0.784/0.059，COD10K0.841/0.735/0.028，NC4K0.840/0.762/0.046；CHAMELEON0.907/0.851/0.022，未优于原train。频率增强单独、边缘监督单独、两者组合必须拆开比较，另需无高频门控与边缘系数消融。
局部平滑、残差分解和边缘辅助任务都是需审查已有工作的组成，代码本身不能证明独创性。

## 5. C：7月13日AIM相邻层门控融合

### 代码与版本身份
`7月13日 FSP 结构恢复版/methods/zoomnext/fsp_july13.py`：AdjacentInteractionBlock、EffB1_ZoomNeXt_FSP。
模型类取自真实7月日志，AIM有历史源码支持。四个aim_4/3/2/1，每个64通道，各20个state_dict条目，共80个新增条目（条目包含BN缓冲，并非80个可训练参数）。旧权重strict=True通过。
不是之后的fsp_legacy_block.py（含pyramid等额外结构），不是后来的fsp_residual.py，更不能默认等同完整发表的FSPNet网络。

### 真实计算
原版当前层C与上级输出P先相加，再送RGPU。此版替换为：

    Cp = CBR3x3(C)
    Pp = CBR3x3(Resize(P))
    (Gc,Gp) = Split(sigmoid(Conv1x1_16to128(ReLU(Conv1x1_128to16(Concat(Cp,Pp))))))
    F = CBR3x3_128to64(Concat(Cp*Gc, Pp*Gp))
    decoder_out = original_hmu(F)

门控是每位置每通道的独立Sigmoid，两路不保证和为1。这里没有外加C+P残差，没有全局平均池化。stage5仍是原版；stage4到1各用独立AIM，顺序4→3→2→1。

### 可用方法段落
在四个相邻解码层之间引入门控融合模块，分别对当前尺度特征与上一级解码输出进行投影，通过联合特征预测两路门控，再将加权特征拼接压缩后输入原解码单元。该结构以可学习融合替代原始逐层直接相加。

### 证据边界
旧7月NC4K0.839/0.759/0.046；旧完整四集：CHAMELEON0.899/0.841/0.023，CAMO0.836/0.779/0.059，COD10K0.835/0.726/0.029，NC4K上述值。
恢复后9月重新训练：CHAMELEON0.900/0.840/0.024，CAMO0.825/0.763/0.062，COD10K0.830/0.719/0.030，NC4K0.832/0.750/0.048。结构对齐不等于训练稳定复现，不能把旧权重与重训结果混写。
参数10,891,332，相对原版10,283,588增加607,744。适合作为借鉴方法/结构对照；优先完成来源核对，不宜直接声称自主完整FSPNet创新。
消融：原相加、仅拼接投影、带独立门控、不同接入层。

## 6. D：RGPU全组信息汇总与门控残差交互

### 代码及接入
`ZoomNeXt-RGPU全组交互-20260915/methods/zoomnext/rgpu_all_group.py`：AllGroupRGPU、EffB1_ZoomNeXt_AllGroup。五个hmu全部替换，其他结构原版。

### 动机
原RGPU有顺序传递路径，前组不能通过该顺序路径直接获得后组的信息。原模块并非完全无全组信息：原有后端门控也会利用多个组的gate特征。新变化是在逐组交互开始之前，将全部输入组的汇总注入各组，而非声称首次提供任意组间交互。

### 真实计算
64通道经原expand_conv扩展至192，默认6组各32通道。在每个空间位置进行所有输入组的可学习压缩：

    [X1,...,X6] = Split(original_expand(X))
    C = GELU(Conv1x1_192to32(Concat(X1,...,X6)))
    Gi = sigmoid(Conv1x1_64to32(Concat(Xi,C)))
    Xi_new = Xi + tanh(ai) * Gi * C

每组独立门控和一个可训练标量ai，每层6个ai，各层独立；ai初始化为0。然后完整沿用原顺序interact、gate_genator、fuse与输出残差。
“全组”指同一位置的所有通道组；这里没有全图空间池化或token自注意力。ai经tanh后可为负，因此允许增强或抑制共享信息，不能写成[0,1]概率。

### 可用方法段落
在原有逐组递推交互之前增加共享特征汇总支路，将所有通道组压缩为同一空间位置的共享表示，并由各组自身特征与共享表示共同生成门控。通过零初始化的有界残差系数，逐步学习共享信息的注入强度，同时保留原有组间递推、输出门控与残差结构。

### 证据与消融
参数10,376,738，新增93,150，约0.91%。CPU检查：零初始化和关闭支路时与同初始化原版输出一致，非零支路有效，五级梯度检查通过。这些不等于性能或可复现性证明。
用户最新NC4K记录0.841/0.764/0.045，是本表单次记录中三项均最好的候选；需收集完整四集日志和重复实验。
消融应拆开共享汇总、组特异门控、可学习系数、接入层；成本应测参数、FLOPs、显存和速度，不能仅从参数少推断无开销。

## 7. E：SimpleASPP五分支自适应加权

### 代码及接入
`ZoomNeXt-ASPP分支加权-20260917/methods/zoomnext/aspp_weighted.py`：WeightedSimpleASPP、EffB1_ZoomNeXt_WeightedASPP。只替换tra_5；三个输入尺度调用同一模块，参数共享，权重按各次输入产生。MHSIU和RGPU保持原版。

### 原结构与动机
原模块包含局部特征、三个串联膨胀卷积层输出以及全局池化分支，共五路，经拼接和卷积融合。不是标准“多个不同膨胀率并联”的简单套用图。原融合已经可学习，但没有显式的按输入变化的五路标量门控。新设计探索图像内容相关的分支选择。

### 真实计算
设原五路为Y0(global)、Y1(local)、Y2/Y3/Y4(连续膨胀卷积结果)，每路64通道。

    F = Concat(Y0,Y1,Y2,Y3,Y4)  # 320 channels
    z = Conv1x1_16to5(ReLU(Conv1x1_320to16(GAP(F))))
    w = 5 * Softmax_branch(z)
    output = original_fuse(Concat(w0*Y0,...,w4*Y4))

每个样本输出五个标量，广播到该分支所有通道和空间位置；不是像素级权重，也不是MHSIU三输入尺度权重。末层卷积权重和偏置置零，初始wi=1，五个权重和为5；乘5是为了保持原特征幅度。不能写成实际乘数和为1。

### 可用方法段落
保留原SimpleASPP的特征提取与拼接融合，在其五路输出上加入输入相关的分支选择器。选择器基于拼接特征的全局描述产生归一化权重，并通过幅度校正保持等权初始化时与原模块等价，从而学习不同上下文分支对当前输入的贡献。

### 证据与消融
参数10,288,809，新增5,221，约0.051%。用户最新NC4K0.839/0.761/0.046，Sm/wFm小幅改善，MAE持平。完整四集和重复实验待补。
消融：原融合、仅可学习常量权重、输入相关权重、初始化方式、不同权重生成压缩维数。机制上接近已有分支选择/通道注意力类思路，需要文献核查，不能仅因改了class就声称独立创新。

## 8. 如何组织论文

候选主线不是“凑五个模块”，而是选择能形成清晰问题链的少量模块：例如RGPU解决解码阶段的组信息交换，②研究高分辨率细节和轮廓监督，ASPP研究深层多分支选择。A可作为尺度融合方向的备选，C更适合保留为历史借鉴对照。这个优先级基于当前记录和代码区分度，不是导师评审结论，也未核查文献新颖性。

组合仅是待验证假设。若确定两模块，至少运行原版、A、B、A+B；三个模块完整组合矩阵8组，计算不足时与导师约定先单模块再关键组合。组合实验应重新训练，不能拼接各自最佳指标或把多个单模块权重当成联合训练结果。

可调整的五章安排：
1. 绪论：任务、研究问题、相关工作、本文贡献与结构。
2. 理论基础：分割、编码解码、ZoomNeXt、尺度融合、注意力、损失与指标。
3. 数据集与实验协议：公开数据来源、实际文件清单、配对检查、训练/测试划分、复现实验、环境与评价方法。若没有自建数据贡献，不应将公开数据介绍包装为数据集创新。
4. 基于ZoomNeXt的改进方法：按问题—结构—公式—复杂度描述经过筛选的主要候选。
5. 实验分析与讨论：同协议基线、消融、相关方法对比、泛化与失败案例、局限。总结展望可按学校模板另设第六章，或置于第五章末。
